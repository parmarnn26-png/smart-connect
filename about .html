ℹ️ About Smart Connect

Smart Connect is a simple web-based permission demo created for learning how modern browsers handle camera and location permissions.

The website does not bypass browser security. Camera and location features work only when the user gives permission.

🔐 Privacy

Camera:
Camera access requires browser permission.

Location:
Location access requires browser permission.

User Control:
The user can deny or revoke permission through the browser settings.

📚 Learning Project

This project is intended for learning HTML, CSS, JavaScript and browser permission APIs in a safe and permission-based environment.
